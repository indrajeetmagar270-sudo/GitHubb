# Student Record and Academic Management System

A console-based Python application developed as part of the **Computational Thinking and Basic Programming** course. This project demonstrates a structured software development lifecycle—moving from problem analysis and algorithm design to flowcharts, pseudocode, implementation, and systematic testing.

---

## Objective

The primary goal of this system is to apply core computational thinking and software engineering principles to manage academic records efficiently. The focus is on logical reasoning, structured programming, and systematic documentation rather than building a complex graphical software application.

---

## System Requirements

### Functional Requirements
* **Add Student Information:** Input and store student personal details, 5 subject marks, and attendance percentage.
* **Display Student Records:** View complete academic profiles for all recorded students.
* **Search Student Details:** Find specific student records using their PRN (Permanent Registration Number).
* **Calculate Performance Metrics:** Compute subject averages and assign academic grades dynamically.
* **Exit Application:** Terminate the program cleanly via a menu choice.

### Non-Functional Requirements
* **Simplicity:** Console-driven interface with clear inputs and prompt prompts.
* **Ease of Use:** Intuitive numerical menu navigation.
* **Accuracy:** Precise floating-point calculations for grade determinations and averages.
* **Reliability:** Dynamic checks for empty record lists and unrecorded PRNs.
